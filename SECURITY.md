# Security

The 0.1.x experimental preview is intended for a trusted local computer and
trusted protocol/configuration files. The resident interface uses a local Unix
domain socket; network-facing operation and untrusted multi-user isolation are
not supported. Keep station stores and sockets accessible only to intended users.

This software is not a hardware emergency-stop or safety-interlock system.
Simulator acceptance does not establish safe operation on physical equipment.

For suspected vulnerabilities, use the repository's private vulnerability-reporting
channel when available. If it is unavailable, contact a maintainer privately before
sharing exploit details; do not post secrets or exploitable details in a public issue.
Only the latest preview is maintained, without a guaranteed response time.
